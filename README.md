# Jakt og felling i Norge

Hva betyr «fire dyr» på en fellingstillatelse? Svaret avhenger av arten og av om valdet har en godkjent bestandsplan. Denne digitale læringsstien bruker slike saker til å forklare jaktrett, kvoter og offentlige vedtak i norsk viltforvaltning.

**6 etapper · 13 oppgaver · omtrent 20 minutter · bokmål**

## Bruk læringsstien

Åpne prosjektets GitHub Pages-side, eller last ned `index.html` og åpne filen i en nettleser med JavaScript aktivert. Hele læringsstien, inkludert fotografier, logo og oppgaver, fungerer uten nett. Kildelenkene åpner eksterne nettsider.

Studenten får begrunnet tilbakemelding på seks flervalgsoppgaver. I sju kortsvarsoppgaver skriver studenten en egen begrunnelse før fasiten vises, sammenligner med to vurderingspunkter og kan merke oppgaven for repetisjon. Oppsummeringen viser hvilke oppgaver studenten vil øve mer på.

Svar og fremdrift lagres lokalt når nettleseren tillater det. Økten fungerer også når lokal lagring er slått av. Svarene sendes ikke inn til lærer eller GitHub.

## Publiser med GitHub Pages

1. Pakk ut ZIP-filen. Last opp innholdet til roten av et GitHub-repo på grenen `main`. Da ligger `index.html`, `README.md`, `KILDER.md` og den tomme filen `.nojekyll` på samme nivå. Velg **Commit changes**. Med GitHub Free brukes et offentlig repo for Pages.
2. Åpne **Settings → Pages** i repoet. Under **Build and deployment** velger du **Deploy from a branch**.
3. Velg grenen **main** og mappen **/(root)**. Trykk **Save**.
4. Når publiseringen er ferdig, åpne **Visit site** under **Settings → Pages**. Dette er adressen du kan dele med studentene.

`.nojekyll` lar Pages publisere de ferdige filene direkte. Senere oppdateringer publiseres når du lagrer en ny versjon på den valgte grenen. [GitHubs veiledning om publiseringskilde](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) · [Opprette og åpne et Pages-nettsted](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)
